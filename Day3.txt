## 1. What is Linux?

Linux is an open-source, Unix-like operating system kernel that manages hardware and system resources.

### Main Functions of Linux
- Process Management
- Memory Management
- File System Management
- Device Management
- User and Permission Management
- Network Management
- Security Management

### Examples of Linux Distributions
- Ubuntu
- Debian
- Red Hat Enterprise Linux (RHEL)
- Fedora
- Linux Mint

---

## 2. Linux Architecture

Linux architecture consists of different layers:

1. **Hardware:** CPU, RAM, SSD, Keyboard and Network Card.
2. **Kernel:** Manages hardware and system resources.
3. **Shell:** Provides a command-line interface to interact with the operating system.
4. **Applications:** Programs such as Nginx, Docker and MySQL.
5. **User:** Interacts with the system.

### Important Components

**Kernel**
- Core component of Linux.
- Manages CPU, RAM, processes, devices and networking.

**Shell**
- Command-line interpreter.
- Examples: Bash, Zsh and Fish.

**File System**
- Organizes files and directories.
- Linux uses a hierarchical directory structure starting from `/`.

| Feature | Linux | Windows |

| Developer | Open-source community and organizations | Microsoft |

## 4. What is a Boot Loader?

A Boot Loader is a program that loads the operating system kernel into memory during the computer startup process.

### Example
GRUB – Grand Unified Bootloader.

### Functions of Boot Loader
- Loads the Linux kernel.
- Provides an operating system selection menu.
- Supports multiple operating systems.
- Allows selection of different kernel versions.

### Linux Boot Process

1. BIOS / UEFI
2. Boot Loader (GRUB)
3. Linux Kernel
4. Init System (systemd)
5. System Services
6. Login

## 5. History of Linux

| Year | Event |
|---|---|
| 1969 | UNIX created at Bell Labs |
| 1983 | GNU Project started by Richard Stallman |
| 1991 | Linus Torvalds announced Linux |
| 1992 | Linux kernel adopted GNU GPL license |
| 1993 | Debian and Slackware distributions appeared |
| 1994 | Linux Kernel 1.0 released |
| 1996 | Tux became the Linux mascot |
| 2004 | Ubuntu 4.10 released |
| 2005 | Git created by Linus Torvalds |
| 2008 | First Android phone launched using Linux kernel |

### Important People
- **Linus Torvalds:** Creator of the Linux kernel.
- **Richard Stallman:** Founder of the GNU Project.
- **Dennis Ritchie:** Co-creator of UNIX and creator of C.
- **Ken Thompson:** Co-creator of UNIX.

---

## 6. UNIX vs GNU vs Linux

**UNIX**
- Operating system family.
- Developed at Bell Labs.
- Influenced modern operating systems.

**GNU**
- Free software project started in 1983.
- Developed tools such as Bash, GCC and GNU utilities.

**Linux**
- Kernel developed by Linus Torvalds in 1991.

**GNU/Linux**
- GNU tools combined with the Linux kernel to form a complete operating system.

## 7. Basic Linux Commands

| Command | Description |
|---|---|
| `pwd` | Shows current directory |
| `ls` | Lists files and directories |
| `cd` | Changes directory |
| `mkdir` | Creates a directory |
| `touch` | Creates a file |
| `cat` | Displays file content |
| `whoami` | Shows current username |
| `uname -a` | Shows system information |
| `ps aux` | Displays running processes |
| `free -h` | Displays memory information on Linux |

### Practical Commands

```bash
# Check current directory
pwd

# Create a directory
mkdir linux-practice

# Enter directory
cd linux-practice

# Create files
touch notes.txt commands.txt

# List files
ls -l

# Write content
echo "I am learning Linux" > notes.txt

# Read file
cat notes.txt
```

Note: These commands were introduced for practice. They are not all Linux-only; several also work on macOS.
